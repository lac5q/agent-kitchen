## How to use this log

Record UAT findings here as they are discovered. Keep entries concise, reproducible, and free of real PII. Use sanitized fixture IDs from `apps/memroos/data/uat-fixtures/` or fake `example.test` users only.

### Status values

| Status | Meaning |
| --- | --- |
| `New` | Finding needs triage. |
| `Triaged` | Owner/severity confirmed. |
| `In Progress` | Fix or mitigation is underway. |
| `Blocked` | Cannot proceed without dependency/input. |
| `Ready for Retest` | Fix is available for UAT verification. |
| `Closed` | Retest passed or issue accepted as non-bug. |

### Severity values

| Severity | Meaning |
| --- | --- |
| `Critical` | Security/privacy breach, data loss, or app-wide outage. |
| `High` | Broken primary workflow, incorrect authorization, or misleading compliance state. |
| `Medium` | Important feature defect with workaround. |
| `Low` | Cosmetic, copy, minor edge-case, or documentation-only issue. |
