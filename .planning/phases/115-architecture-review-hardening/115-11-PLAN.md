# 115-11 Shared Contract Manifest and Schema Drift Gate

Status: completed 2026-06-27

## Objective

Close the generated/shared-schema consolidation portion of `ARCHREV-06` with a repo-level contract manifest and drift checker across the app, TypeScript SDK, Python SDK, MCP facade, REST/OpenAPI discovery, and A2A discovery.

## Scope

- Add `contracts/memroos-contracts.json` as the shared manifest for shipped machine contracts:
  - `public-eval-api.v1`
  - `memroos-a2a.v1`
  - `memroos-mcp-tools.v1`
- Track schema sources, discovery surfaces, checked artifacts, public eval response fields, and A2A task states in the manifest.
- Add `scripts/check-contract-manifest.mjs` to validate:
  - contract IDs and headers match app/SDK/MCP constants
  - public eval response fields remain visible in app, TypeScript SDK, and Python SDK validators
  - A2A task states remain aligned with the shared `A2A_TASK_STATES` source
  - discovery route files and schema source files exist
- Add `npm run check:contracts` as the monorepo gate.

## Verification

- `node --test scripts/check-contract-manifest.test.mjs`
- `npm run check:contracts`

## Notes

- This intentionally avoids introducing code-generation dependencies in this slice. The manifest gives the current handwritten contracts a shared source and drift gate; future SDK generation can build from the same manifest if needed.
