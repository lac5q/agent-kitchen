# 115-08 Plan: Public Eval REST OpenAPI Contract

## Objective

Advance `ARCHREV-06` by publishing a machine-readable REST/OpenAPI contract for the public eval v1 API from the shared public eval contract module.

## Scope

- Add an OpenAPI 3.1 document builder beside the public eval v1 route contract.
- Expose `GET /api/public/v1/openapi` as an unauthenticated discovery route.
- Cover the public eval v1 trace, run, and proposal endpoints with bearer auth, request, response, and error schemas.
- Add regression coverage proving the OpenAPI paths stay aligned with the shared route contract table.
- Document the OpenAPI discovery route in `docs/rest-api.md`.

## Non-Goals

- This does not complete all of `ARCHREV-06`.
- No A2A schema generation or MCP tool schema export in this slice.
- No public eval API response body changes.
- No new OpenAPI dependency or generated SDK publishing workflow.

## Done Criteria

1. `/api/public/v1/openapi` serves OpenAPI 3.1 JSON without tenant auth.
2. The OpenAPI document advertises `public-eval-api.v1` and the tenant bearer auth scheme.
3. The OpenAPI paths are derived from the shared `publicEvalApiV1Contract` route table.
4. REST docs point external consumers to the machine-readable public eval v1 spec.
