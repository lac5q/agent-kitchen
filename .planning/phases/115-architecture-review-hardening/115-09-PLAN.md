# 115-09 Plan: MCP Tool Schema Export Contract

## Objective

Advance `ARCHREV-06` by giving the MemRoOS MCP facade a machine-readable tool schema/export contract backed by the same registry used for FastMCP registration.

## Scope

- Track every top-level MCP tool registered through `_mcp_tool`.
- Export a stable `memroos-mcp-tools.v1` contract with tool name, description, `inputSchema`, and `outputSchema`.
- Expose the contract through the `mcp_tool_contract` tool and `mcp://tools/contract` resource.
- Add a `check:mcp-schema` npm gate for the MCP schema contract.
- Document the contract export in `docs/integrations/mcp.md`.

## Non-Goals

- This does not complete all of `ARCHREV-06`.
- No A2A schema generation in this slice.
- No runtime behavior change for existing MCP tool implementations.
- No public exposure policy change for the HTTP MCP endpoint.

## Verification

- `npm run check:mcp-schema`
- `.venv/bin/python -m pytest services/knowledge-mcp/tests/test_knowledge_system.py -q`
- `bash -n scripts/memroos-mcp.sh`
- `.venv/bin/python -m compileall services/knowledge-mcp/knowledge_system`
- `git diff --check`

## Done Criteria

1. Every `_mcp_tool`-registered tool appears in the exported contract.
2. Every exported tool has a non-empty description, object `inputSchema`, and `outputSchema`.
3. Required/default parameters are represented in the exported input schemas.
4. The schema gate can be run from the monorepo root.
