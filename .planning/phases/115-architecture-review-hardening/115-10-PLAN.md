# 115-10 A2A OpenAPI Schema Contract

Status: completed 2026-06-27

## Objective

Close the A2A portion of `ARCHREV-06` with a stable, machine-readable contract for MemRoOS A2A discovery and JSON-RPC dispatch without replacing the existing broker implementation.

## Scope

- Add `apps/memroos/src/lib/a2a/contract.ts` as the A2A contract source for:
  - contract id `memroos-a2a.v1`
  - `X-Memroos-Contract` response headers
  - runtime Zod validation for agent cards, messages, tasks, task events, and task states
  - OpenAPI 3.1 discovery for well-known agent-card routes and `/api/a2a`
- Add unauthenticated OpenAPI discovery at `/api/a2a/openapi`.
- Add the contract header to both well-known agent-card endpoints.
- Add `npm run check:a2a-schema` as the repeatable verification command.

## Verification

- `npm run test --workspace apps/memroos -- --run src/lib/a2a/__tests__/contract.test.ts src/lib/a2a/__tests__/agent-card.test.ts src/app/api/a2a/openapi/__tests__/route.test.ts`

## Notes

- This slice does not mark `ARCHREV-06` complete. Generated/shared-schema consolidation remains open.
