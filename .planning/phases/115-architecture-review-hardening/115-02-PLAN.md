# 115-02 Plan: Agent OS Architecture Identity and Module Map

## Objective

Complete `ARCHREV-02` by making the architecture documentation describe MemRoOS as an agent operating system with a broker kernel, a shipped-domain module map, and explicit placement rules for Next.js app code, Python services, scripts, docs, and planning artifacts.

## Scope

- Update `docs/architecture.md` to use the agent OS and broker-kernel framing.
- Add a module map for shipped domains with route and library ownership.
- Add Python service boundaries for orchestration, memory, knowledge MCP, and voice.
- Add script boundaries for provisioning, validation, eval, launcher, and maintenance tools.
- Add placement rules for `apps/memroos/src/app`, `apps/memroos/src/lib`, `services`, `scripts`, `docs`, and `.planning`.

## Non-Goals

- No runtime architecture changes.
- No new service, route, or dependency.
- No claims that public deployment approval is implied by documentation closure.
