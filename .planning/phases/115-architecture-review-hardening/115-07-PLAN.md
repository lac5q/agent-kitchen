# 115-07 Plan: Python SDK Public Eval Contract Alignment

## Objective

Advance `ARCHREV-06` by aligning the Python eval SDK with the public eval v1 contract and proving the SDK against a running MemRoOS app.

## Scope

- Add Python SDK runtime validation for successful `EvalSubmitResult` responses.
- Export the public eval v1 contract ID and contract header constants from the Python SDK.
- Wire `MemroosClient.submit_trace()` through the response contract validator.
- Add a gated live Python SDK smoke test helper that submits a realistic trace to a running MemRoOS app.
- Add a package README so the declared Python package metadata is installable in editable/dev mode.

## Non-Goals

- This does not complete all of `ARCHREV-06`.
- No A2A schema generation, MCP tool schema export, ChatGPT OpenAPI generation, or REST reference generation in this slice.
- No public API response body changes.

## Verification

- `./.venv/bin/python -m pip install -e '.[dev]'`
- `./.venv/bin/python -m pytest tests/`
- Live smoke against a real local app:
  - app: `SQLITE_DB_PATH=/tmp/memroos-py-sdk-smoke.db MEMROOS_INTERNAL_API_KEY=memroos-py-sdk-smoke-key NEXT_TELEMETRY_DISABLED=1 npm run dev -- --port 3218`
  - SDK: `MEMROOS_SDK_SMOKE=1 MEMROOS_BASE_URL=http://localhost:3218 MEMROOS_API_KEY=memroos-py-sdk-smoke-key ./.venv/bin/python -m pytest tests/test_smoke_live.py -v`

## Done Criteria

1. Python SDK `submit_trace()` rejects malformed successful response bodies.
2. The Python SDK exports the public eval v1 contract constants and error type.
3. The Python SDK package can install in editable dev mode from its declared metadata.
4. A live Python SDK smoke can submit a sample trace against a running app and receive numeric W/layer output.
