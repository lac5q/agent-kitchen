# 115-06 Plan: Public Eval Contract First Slice

## Objective

Advance `ARCHREV-06` by moving the public eval v1 API and TypeScript SDK off purely copied/inline contracts and proving the SDK against a running MemRoOS app.

## Scope

- Add an app-side public eval v1 contract helper with runtime validation for `AgentEvalTrace` requests and `EvalSubmitResult` responses.
- Replace the inline `/api/public/v1/traces` trace guard with the contract helper.
- Add a stable `X-Memroos-Contract: public-eval-api.v1` response header for public eval trace submissions.
- Add TypeScript SDK runtime validation for `EvalSubmitResult`.
- Add a gated live SDK smoke test that submits the SDK sample trace to a running MemRoOS app.
- Update the SDK sample trace to satisfy the evaluator's cross-family judge guard.

## Non-Goals

- This does not complete all of `ARCHREV-06`.
- No A2A schema generation, MCP tool schema export, ChatGPT OpenAPI generation, REST reference generation, or Python SDK generation in this slice.
- No public API response body changes.

## Done Criteria

1. The public trace route validates MemRoOS JSON trace payloads through a shared app contract helper.
2. The public trace route response body is validated before returning to SDK callers.
3. SDK `submitTrace()` rejects malformed successful response bodies.
4. A live SDK smoke can submit a sample trace against a running app and receive numeric W/layer output.
