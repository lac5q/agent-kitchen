# Phase 146 Plan 01 — Paperclip Tenant Integration + Cost Delegation

**Phase:** 146  
**Milestone:** v8.5  
**Requirements:** FLEET-17..21  
**Status:** potential plan  

## Goal

Integrate Paperclip as a **parallel tenant / product plane** that MemroOS can subscribe to and that owns company-level budgets. MemroOS does not re-implement Paperclip board UX or budget hard-stops.

## Tasks

1. Write `docs/integrations/paperclip.md` contract:
   - What Paperclip owns (companies, issues, budgets, approvals, activity log)
   - What MemroOS owns (cross-runtime registry, memory, fleet governance, A2A)
   - Auth: bearer / agent_api_keys; no shared secret dump
2. Inbound adapter or MCP consumer: ingest Paperclip agent heartbeats / activity into MemroOS registry or NOC strip (minimal viable)
3. Cost delegation: fleet cost queries that need hard-stop behavior **call Paperclip** or display Paperclip as source of truth — document API path
4. Outbound optional: MemroOS can open a Paperclip issue via HTTP adapter when a fleet incident needs company task tracking
5. Do **not** federate multiple Paperclip servers in this phase

## Success criteria

1. Contract doc exists and matches audit findings (single-server Paperclip, passive Hermes adapters)
2. At least one live path: Paperclip event → MemroOS visibility **or** MemroOS incident → Paperclip issue
3. Budget hard-stop remains Paperclip's responsibility (cited in contract)

## Verification

- Contract checklist complete
- Smoke against local or Oracle Paperclip instance if available; otherwise mock + contract tests
