# Phase 106 Plan 02 - Real Behavioral Sandbox Scorer

## Goal

Finish `SKILLOPT-HARDEN-01` by replacing simulated or randomized behavioral scoring with a deterministic sandbox-backed scorer for SkillForge instruction and skill proposals.

## Scope

- Locate the Phase 94 behavioral A/B scorer that still uses simulated/random W values.
- Define the sandbox contract for running current skill version and proposed skill version against the same held-out tasks.
- Record baseline W, validation W, held-out W, split ids, scorer version, and evaluator receipts in the existing SkillForge proposal traceability fields.
- Fail closed when held-out tasks, scorer receipts, sandbox execution, or non-regression thresholds are missing or stale.
- Add regression tests proving deterministic scores, true baseline comparison, fail-closed missing evidence, and no fixed pass-rate fallback.

## Verification Plan

- Run focused scorer tests added for this plan.
- Run SkillForge eval-gate, proposal, approval, and worker tests.
- Run repository typecheck.
- Run `git diff --check`.
- Run GitNexus impact before editing scorer symbols and `detect_changes()` before completion.

## Exit Criteria

Phase 106 can close only after SkillForge held-out eval uses the real sandbox scorer and `SKILLOPT-HARDEN-01` is marked complete in `.planning/REQUIREMENTS.md`.
