# Phase 107 Plan 01 — Agent Context Bus and Synchronous Agent Communication

Status: Complete (2026-06-04)

## Goal

Implement a MemRoOS-backed agent communication bus so registered agents can exchange durable context, synchronously wait for replies, acknowledge messages, and request memory persistence through REST and the unified knowledge MCP facade.

## Scope

- Add an additive `agent_context_messages` table created by the bus module on first use.
- Add route-local agent-key-authenticated REST endpoints for send, list, get/wait, ack, and reply.
- Add knowledge MCP tools: `agent_context_send`, `agent_context_inbox`, `agent_context_reply`, `agent_context_ack`.
- Preserve provenance and security by running content scanning and audit writes on every bus write.
- Support optional memory-save receipts for context-sync and knowledge-save handoffs.
- Keep data-access authority in the MemRoOS control layer: agent scans and declared capabilities may guide requested scope, but deterministic policy scripts and registry checks decide access and fail closed on ambiguous or self-declared claims.
- Carry responsible user identity with every agent-mediated access: user id, tenant/project, user role, OAuth subject/scope/consent, encrypted credential reference, and agent id/version flow into data-element policy decisions without exposing raw OAuth tokens to memory, audit, prompts, indexes, or agent payloads.
