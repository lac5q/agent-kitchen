# 141-01 Plan: Save-Artifact Gate + Auto-README Update

## Objective

1. **ARTGATE-01**: When the agent produces a long-form artifact (report, document, deck) for a loaded space, the operator gets a single "Save to <space>?" prompt — no recurring permission dialog.
2. **ARTGATE-02**: On save, the agent appends the artifact to the Document Directory (or creates a new document) and emits a run-ledger event with the resource id and belief stage.
3. **ARTGATE-03**: On save, the agent updates the space README's "Last artifact" pointer in the Document Directory; the operator can disable auto-update per-space; auto-updates are policy-receipted.

- `apps/memroos/src/lib/workspace.ts` — Phase 137: getActiveWorkspace, isWriteTargetInWorkspace.

## Design

### Schema: v10 migration — `space_artifact_settings` table

```sql
CREATE TABLE IF NOT EXISTS space_artifact_settings (
  space_id      TEXT PRIMARY KEY REFERENCES spaces(id) ON DELETE CASCADE,
  auto_readme_update INTEGER NOT NULL DEFAULT 1,
  last_artifact_resource_id TEXT,
  last_artifact_name TEXT,
  last_artifact_saved_at TEXT,
  updated_by TEXT,
  updated_at TEXT
);
```

### `apps/memroos/src/lib/artifact-gate.ts` — NEW

```ts
export interface SavePromptResult {
  spaceId: string;
  spaceName: string;
  artifactName: string;
  artifactType: string;
  prompt: string;
}

// ARTGATE-01: Generate a save prompt for a long-form artifact
export function promptSaveArtifact(db, input: { spaceId: string; artifactName: string; artifactType: string }): SavePromptResult;

// ARTGATE-02: Save an artifact to the document directory + emit run-ledger event
export function saveArtifact(db, input: { spaceId: string; artifactName: string; artifactType: string; resourceId: string; beliefStage: string; actorId: string; purpose?: string }): { documentDirectoryEntry: DocumentDirectoryEntry; readmeUpdated: boolean };

// ARTGATE-03: Set auto-README update enabled/disabled per space
export function setAutoReadmeUpdate(db, input: { spaceId: string; enabled: boolean; actorId: string }): void;

// Check if auto-README update is enabled for a space
export function isAutoReadmeUpdateEnabled(db, spaceId: string): boolean;

// ARTGATE-03: Get the last artifact pointer
export function getLastArtifactPointer(db, spaceId: string): { resourceId: string | null; name: string | null; savedAt: string | null } | null;
```

Implementation details:
- `promptSaveArtifact`: Look up the space name. Return a prompt string like `Save to <spaceName>?`. This is a one-time confirmation — the caller saves the artifact only after the operator confirms.
- `saveArtifact`: 
  1. Check `assertWritableSpace` (shared spaces are read-only).
  2. Check `isWriteTargetInWorkspace` (must be the active workspace).
  3. Create or update a Document Directory entry for the artifact (import from write-rules.ts).
  4. Write audit_entries with event_type='artifact.saved', metadata with { resourceId, beliefStage, artifactName, artifactType, actionType }.
  5. If auto-README is enabled, update `space_artifact_settings` with last_artifact_resource_id, last_artifact_name, last_artifact_saved_at. Write audit_entries with event_type='artifact.readme_updated'.
  6. Return { documentDirectoryEntry, readmeUpdated }.
- `setAutoReadmeUpdate`: Upsert into space_artifact_settings. Write audit_entries with event_type='artifact.auto_readme_toggled'.
- `isAutoReadmeUpdateEnabled`: Query space_artifact_settings. Default to true if no row exists.
- `getLastArtifactPointer`: Query space_artifact_settings for last_artifact_* fields.
