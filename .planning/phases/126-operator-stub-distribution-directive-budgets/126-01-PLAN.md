# 126-01 Plan: Operator-Stub Distribution + Directive Budgets

## Objective

(1) ENTOPS-06 directive budgets: per-tenant config (default 200 lines), warn+diff-against-canonical, NEVER auto-trim — build the budget logic + admin endpoint. (2) ENTOPS-04 installer operator-stub defaults: when `MEMROOS_OPERATOR_URL` is set, the installer writes an operator-pointing MCP stub and disables git fallback; `--local` is the explicit solo escape hatch. (3) ENTOPS-05 honest stub: the MDM-deployable / locked-down-Mac verification is infrastructure we don't have — we ship the installer mechanics + a first-day verification script, and explicitly mark the MDM/IdP demo as unbuilt with a handoff note.

## Scope (code)

- ENTOPS-06: directive budget library + admin endpoint + `directive_diff` (warn, never delete). Model on `apps/memroos/src/lib/skill-budget.ts`.
- ENTOPS-04: installer gains operator-stub mode. `scripts/install-agent-integrations.sh` + `scripts/setup-codex-cloud.sh` honor `MEMROOS_OPERATOR_URL`; when set, MCP block points at operator (HTTP), no git-clone fallback; `--local` preserves today's behavior.
- ENTOPS-05 (code slice): `scripts/verify-first-day-onboarding.sh` — a verification script a new hire runs (checks env, MCP reachability, directive present). The MDM-deployable / no-admin-Mac / IdP pieces are HONEST STUBS (documented, not faked).

## Non-goals / honest stubs (NOT built)

- No real OAuth/IdP integration (ENTOPS-04 IdP half) — installer uses existing API-key/operator-URL; OAuth device flow is a documented follow-up.
- No real MDM packaging or signed `.pkg` — the verification script is shippable; MDM distribution is operator infrastructure.
- No S9/S10 live demos (require the hosted operator + real locked-down Mac).
- Directive budgets never auto-trim user content (ENTOPS-06 hard rule).

## Existing surfaces (verified)

- `apps/memroos/src/lib/skill-budget.ts` — budget accounting model to copy (ok/watch/over, char/token, recommendations).
- `scripts/install-agent-integrations.sh` — `upsert_yaml/toml/json_mcp_block`, TARGETS list, copies `agents/AGENTS_TEMPLATE.md` verbatim. `MEMROOS_OPERATOR_URL` does NOT exist yet.
- `scripts/setup-codex-cloud.sh` — uses `MEMROOS_APP_URL` (alias target for ENTOPS-04).
- `apps/memroos/src/app/api/audit/knowledge/route.ts` (Phase 125) — operator API-key auth pattern to reuse for the budget admin endpoint.

## Design Contract

### ENTOPS-06 directive budget

`apps/memroos/src/lib/directive-budget.ts` (NEW): `computeDirectiveBudget(directiveText, config)` → `{status: 'ok'|'watch'|'over', lineCount, budgetLines: 200, utilization, diff}`. `directive_diff(local, canonical)` returns added/removed/changed lines, NEVER mutates. `loadDirectiveBudgetConfig()` reads `MEMROOS_DIRECTIVE_BUDGET_LINES` (default 200).

`POST /api/directives/budget` (admin): per-tenant override of budget lines. `GET /api/directives/diff?tenant=`: returns the warn-only diff.

### ENTOPS-04 operator-stub installer mode

`install-agent-integrations.sh`: new flag/mode. If `MEMROOS_OPERATOR_URL` set → write operator MCP block:
```yaml
memroos:
  command: /bin/bash
  args: [-lc, exec curl -sSf "${MEMROOS_OPERATOR_URL}/api/mcp" ] # operator-stub, no local clone
```
(oexact transport TBD by worker — could be a small `memroos-operator-stub.sh` that proxies to the operator URL). Git-clone fallback path: assert it does not exist in operator mode (grep-guard). `--local` flag forces today's local-launch block.

### ENTOPS-05 verification script

`scripts/verify-first-day-onboarding.sh`: checks `~/.memroos/*.env` present, MCP config valid, operator URL reachable, directives present, runs a `knowledge_read` smoke. Exits non-zero with a clear checklist on any miss.

**Verification:**

```bash
cd apps/memroos && npx vitest run src/lib/__tests__/directive-budget.test.ts && npm run typecheck
bash scripts/verify-first-day-onboarding.sh --local  # solo smoke
grep -c "git clone" scripts/install-agent-integrations.sh  # baseline; operator mode must not add one
```

**Success criteria:**
1. ENTOPS-06: budget over→status 'over', diff is warn-only (no write/trim path exists — structural test).
2. ENTOPS-04: operator mode writes operator-pointing block; `--local` writes local block; no git-clone fallback added.
3. ENTOPS-05: verification script runs, produces clear pass/fail checklist.
4. `docs/entops-stub-handoff.md` explicitly lists what's stubbed.

**Escalation:** any auto-trim path; any git-clone fallback in operator mode; solo mode breaking.
