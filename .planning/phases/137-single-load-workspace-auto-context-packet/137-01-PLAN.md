# 137-01 Plan: Single-Load Workspace + Auto Context Packet

## Objective

1. **WORKLOAD-01**: `/load <space>` command primes the Agent Context Packet for the named space and binds it as the active workspace.
2. **WORKLOAD-02**: Load recorded in run ledger as replayable event with actor, space id, timestamp.
3. **WORKLOAD-03**: Adapter calls without active workspace prompt operator to select one (single confirmation, not recurring).
4. **WORKLOAD-04**: Headless runs fail closed (no silent default, no last-used fallback in shared/team mode).
5. **WORKLOAD-05**: Cross-space read allowed but policy-receipted; loaded space is the write target, not the read universe.

## Design

### `apps/memroos/src/lib/workspace.ts` — NEW

```ts
export interface ActiveWorkspace {
  spaceId: string;
  spaceName: string;
  loadedBy: string;  // actor id
  loadedAt: string;  // ISO timestamp
  isHeadless: boolean;
}

// Load a space as the active workspace (WORKLOAD-01)
export function loadWorkspace(db, input: { spaceId: string; actorId: string; isHeadless?: boolean }): ActiveWorkspace;

// Get the current active workspace (or null if none)
export function getActiveWorkspace(db): ActiveWorkspace | null;

// Clear the active workspace
export function clearWorkspace(db): void;

// Prompt for workspace selection when none is active (WORKLOAD-03)
export function promptWorkspaceSelection(db, actorId: string): { needsSelection: boolean; availableSpaces: Space[] };

// Headless fail-closed check (WORKLOAD-04)
export function assertWorkspaceForHeadless(db): ActiveWorkspace; // throws if no workspace in headless mode

// Check if a write target is within the active workspace (WORKLOAD-05)
export function isWriteTargetInWorkspace(db, targetSpaceId: string): boolean;

// Record cross-space read in run ledger (WORKLOAD-05)
export function recordCrossSpaceRead(db, input: { fromSpaceId: string; toSpaceId: string; actorId: string; policyReceiptId: string }): void;
```

### Schema: `active_workspace` table
- `id INTEGER PRIMARY KEY`
- `space_id TEXT NOT NULL REFERENCES spaces(id)`
- `loaded_by TEXT NOT NULL`
- `loaded_at TEXT NOT NULL`
- `is_headless INTEGER NOT NULL DEFAULT 0`
- `cleared_at TEXT` (nullable; when set, this workspace is no longer active)
- Only one row with `cleared_at IS NULL` at a time (enforce in code or via partial unique index)

### Run ledger integration (WORKLOAD-02)
- `loadWorkspace` writes a run ledger event with `actionType: "workspace.load"`, `actor: actorId`, and metadata `{ spaceId, spaceName, isHeadless }`.
- `recordCrossSpaceRead` writes a run ledger event with `actionType: "workspace.cross_space_read"`.

### Context packet priming (WORKLOAD-01)
- `loadWorkspace` calls `buildAgentContextPacket` with the space's project/name as the scope, priming the packet for that space.
