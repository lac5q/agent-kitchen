# Phase 151 — Meeting Ingest Reliability

**Milestone:** v8.11 Unified Meeting Memory  
**Created:** 2026-07-14  
**Updated:** 2026-07-14  
**Status:** planned  
**Requirements:** MEETREL-01, MEETREL-02, MEETREL-03, MEETREL-04

## Goal

Stop Fathom title/dupe misses and make every meeting provider write stable, searchable Markdown with public templates and operator health.

## Tasks

### T1 — Shared transform helpers (MEETREL-01, MEETREL-02)

- Add `scripts/meet-sync/providers/common.py` with `slugify`, `safe_id`, `idempotent_filename`, `yaml_frontmatter`.
- Filename rule: `{date}-{stable_id}.md` where stable_id is `recording_id` / `meeting_id` / Zoom UUID (sanitized). Overwrite on re-ingest — never append `-2`.
- Frontmatter keys: `calendar_title`, `share_url`, `meeting_id`, `source`, plus `title` / `date` when available.

### T2 — Public provider transforms + ingest (MEETREL-03)

- `fathom_transform.py` + `fathom_ingest.sh` (API key from env only).
- `circleback_ingest.py` + `circleback_ingest.sh` (Circleback CLI; idempotent by meeting id).
- `zoom_transform.py` hardened with same frontmatter + id rule.
- Update `meeting-sources.example.json` to point ingestCommand at public providers where applicable.
- Thin-wrap private `~/.memroos/integrations/*` to call public scripts (operator continuity).

### T3 — `meet-sync --health` (MEETREL-04)

- Flag `--health` on `meet-sync.sh`.
- Per enabled source: last status JSON ok/freshness, documentCount, WARN when enabled + empty output (personal Fathom included).

### T4 — Tests

- Unit tests for idempotent filename + frontmatter generation (no live API).

## Success Criteria

1. Same recording/meeting id → same path on re-ingest.
2. Frontmatter present for Fathom/Circleback/Zoom transforms.
3. Public providers under `scripts/meet-sync/providers/`.
4. `--health` exits non-zero on critical failures; WARN lines for empty-enabled sources.

## Out of Scope

- Full re-ingest of all historical meetings during this phase (operator may run separately).
- Memory recall MCP (phase 152).
