# 139-01 Plan: is_shared Single-Boolean Read-Only Toggle

## Objective

1. **SHAREDRO-01**: A single boolean `is_shared` flag on a space makes it read-only for all agents (no writes, no README updates, no document creation); enforced at both the retrieval gate (read-side) and the write-persistence gate (memory adapter write path, save-artifact path, README-update path, document-creation path). Single source of truth (the space record) drives both enforcement points.
2. **SHAREDRO-02**: The `is_shared` flag is policy-receipted: every read or attempted write produces a receipt that references the flag and the space id.
3. **SHAREDRO-03**: Operator UI shows a single "Share read-only" toggle per space; toggling emits a run-ledger event with actor and timestamp; toggling off requires a policy reason.

## Design

### Schema: v8 migration — add `is_shared` column to `spaces`

```sql
ALTER TABLE spaces ADD COLUMN is_shared INTEGER NOT NULL DEFAULT 0;
ALTER TABLE spaces ADD COLUMN shared_reason TEXT;
```

Additive, idempotent (try/catch on ALTER TABLE). No data migration needed — existing spaces default to `is_shared = 0` (not shared).

### `apps/memroos/src/lib/shared-space.ts` — NEW

```ts
// SHAREDRO-03: Set the is_shared flag on a space
export function setSpaceShared(db, input: { spaceId: string; isShared: boolean; actorId: string; reason?: string }): void;

// Check if a space is shared (read-only)
export function isSpaceShared(db, spaceId: string): boolean;

// SHAREDRO-01: Write-persistence gate — throws if space is shared
export function assertWritableSpace(db, spaceId: string): void;

// SHAREDRO-02: Read-side gate — writes a policy receipt for reads on shared spaces
export function assertReadableSpace(db, input: { spaceId: string; actorId: string }): void;

// SHAREDRO-03: Get the toggle history from audit entries
export function getSharedToggleHistory(db, spaceId: string): Array<{ actorId: string; isShared: boolean; reason: string | null; timestamp: string }>;
```

Implementation details:
- `setSpaceShared`: If turning OFF (isShared=false), require a reason — throw if missing. UPDATE spaces SET is_shared=?, shared_reason=?. Write audit_entries with event_type='space.shared_toggle', metadata { isShared, reason, actionType }.
- `isSpaceShared`: SELECT is_shared FROM spaces WHERE id=?. Return false if space not found.
- `assertWritableSpace`: If isSpaceShared returns true, throw Error("space is shared read-only — writes blocked (SHAREDRO-01)"). This is the write-persistence gate.
- `assertReadableSpace`: If isSpaceShared returns true, write audit_entries with event_type='space.shared_read', metadata { spaceId, actorId, isShared: true }. This is the policy receipt for reads on shared spaces. Non-shared spaces: no receipt needed (normal read path).
- `getSharedToggleHistory`: Query audit_entries WHERE event_type='space.shared_toggle' AND entity_id LIKE 'space:%' for the given spaceId.
