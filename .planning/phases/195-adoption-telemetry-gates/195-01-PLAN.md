# 195-01 Plan: Adoption Telemetry + GSD Memory-Receipt Gates

**Milestone:** v8.30 Seamless Memory Adoption
**Created:** 2026-07-26
**Depends on:** Phases 191-194 (the behaviors this measures and gates), Phase 117 (metric plumbing), v8.18 NOCUX (honest-state rules)
**Design:** `.planning/design/memory-adoption-v1.md`

## Progress

- Not started.

## Objective

Answer one operator question from one panel: **are my agents actually using the brain?** Then make the answer hard to regress by gating GSD closeout on memory receipts. This phase lands last because gates over tools that don't exist yet are theatre.

## Baseline (audited 2026-07-26)

- **The metrics are already computed correctly and starved of data.** `apps/memroos/src/lib/efficiency-telemetry.ts` (388 lines) defines five event types (`:11-17`): `retrieval_trace`, `source_read`, `token_ledger`, `operator_question`, `memory_write`, with payload types at `:21-78`. `app/api/operations/noc/route.ts` computes `retrievalBeforeWorkRate` (`:657`) and `rediscoveredFactRate` (`:670`, counters `:564`/`:644`). `components/operations/efficiency-signals.tsx` renders them (`:128`, `:168-171`).
- **Producer reality before v8.30:**

  | Event | Agent-reachable today? |
  |---|---|
  | `retrieval_trace` | ❌ operator-key only, no shipped emitter → **primary metric's table is empty** |
  | `memory_write` | ✅ via `agent_memory_save` only (not the mem0-direct `memory_save`) |
  | `source_read` | ✅ via `agent_tool_outcome_record` |
  | `token_ledger` | ❌ server-side routing only |
  | `operator_question` | ❌ MemRoOS web console chat only |

- `POST /api/operations/telemetry` exists as an explicit operator-key **bootstrap** for hosts where "Claude JSONL / local session ingest is unavailable (e.g. Heroku)" (`route.ts:10-18`) — its existence is the repo admitting the real streams don't flow.
- **NOCUX rules constrain the panel.** `NOCUX-04` requires useful-but-unwired panels sit behind *Show advanced* with an explicit **known-unwired** state, not a generic empty. `NOCUX-02` requires semantic states (live / window-empty / no-history / stale-error / known-unwired). `.planning/notes/operations-noc-real-data-requirements.md` `NOC-10` requires a missing-telemetry checklist until producers exist; `NOC-04` forbids claiming high-salience memories are unused without per-memory access telemetry (Phase 193 SAVEQ-05 supplies it).
- **One after-the-fact detector already works and is narrow.** `scripts/research-without-persist-detector.py` v3.0 (tightened 2026-07-08) scans `~/.hermes/sessions/*.jsonl` for research-grade output (`## Comparison` / `## Benchmark` / `## RCA` / `## Analysis` / `## Recommendations` headers, ≥N external URLs, save-verbs) with no `knowledge_write` call. **Hermes/OpenClaw only**, and findings go to cron logs rather than NOC Attention. Its heuristic vocabulary is directly reusable.
- CI gate pattern to copy: `scripts/check-roadmap-priority.mjs` (+ `.test.mjs`), wired into CI and used as a hard gate today.

## Scope

- A NOC Memory Adoption panel with per-agent and per-harness breakdown.
- Generalize the without-persist detector across Wave-1 harnesses, routing findings to Attention.
- A CI-wired GSD closeout gate requiring probe + learnings receipts.
- Recorded SLOs measured on live operator data.
- Eval fixtures that fail when any seam in the loop disconnects again.

## Non-Goals

- No new metric definitions — reuse the Phase 117 five.
- No fabricated baselines; a rate with no denominator renders as known-unwired, never as 0%.
- No blocking an interactive session on a missing receipt — gates apply at phase/goal boundaries only.
- No hosted/private trace upload.
- No hive-dependent signals in the default view (`NOCUX-01`).

## Design Contract

### D1 — Adoption panel (ADOPTTEL-01)

Five rows, each with an explicit semantic state and a per-agent / per-harness breakdown:

| Metric | Numerator / denominator | Source |
|---|---|---|
| Recall-before-work rate | probes with a result used in first response / working sessions | `retrieval_trace` (Phase 191) |
| Capture-per-session rate | sessions with a capture or typed skip receipt / sessions observed | `agent_session_captures` + hook receipts (Phase 192) |
| Rediscovered-fact rate | writes flagged `isRediscovery` / total governed writes | `memory_write` (existing + Phase 193 parity) |
| Save-quality distribution | histogram of save-quality scores; coach-back rate | Phase 193 SAVEQ-01 |
| Silver→gold throughput | promotions per week, by outcome branch | Phase 193 SAVEQ-04 |

Placement follows the v8.18 layout logic: this answers "is it learning?", so it belongs near `MemoryConsumption` in the main layout **once its producers are verified live** — and behind *Show advanced* with `known-unwired` states until then. A row whose producer is absent says which producer is missing, per `NOC-10`.

### D2 — Generalized detector (ADOPTTEL-02)

Extend `research-without-persist-detector.py` from Hermes/OpenClaw to every Wave-1 session root already known to the sidecar (`~/.claude/projects`, `~/.codex/sessions`, `~/.hermes/sessions`, `~/.openclaw/sessions`, `~/.pi/agent/sessions`). Keep the existing v3.0 heuristics. Broaden the finding types from research-without-persist to also cover **work-without-probe** (a substantive session with no `memory_prior_work` receipt) and **capture-miss** (session ended with neither capture nor skip receipt). Findings become NOC Attention rows with severity, freshness, and a next action — not cron-log lines.

### D3 — GSD closeout gate (ADOPTTEL-03)

`scripts/check-gsd-memory-receipts.mjs`, modelled on `check-roadmap-priority.mjs` and wired into CI. For each phase plan reaching `status: completed`, assert:

1. a `memory_prior_work` receipt id recorded at phase start, **or** an explicit typed skip receipt with a reason, and
2. a learnings/decisions write (governed memory write or `knowledge_write`) at close, **or** a typed skip receipt.

This is why Phases 191-195 use YAML-frontmatter plan files: `status` and `requirements` must be machine-readable for this gate. Per `AUTHGATE-03`'s lesson — *gates that have never been seen to fail are not known to work* — ship a fixture phase plan missing its receipts and assert the gate fails on it.

### D4 — SLOs (ADOPTTEL-04)

Recorded in the roadmap and measured on live operator data, not fixtures:

| Metric | Target |
|---|---|
| Retrieval-before-work rate | ≥70% of working sessions |
| Governed write or typed skip receipt per working session | ≥1 |
| Rediscovered-fact rate | declining trend across 30d |
| Automatic silver→gold throughput | >0 weekly |

Each records its measurement window and the date first measured. A target with no live measurement is reported as *unmeasured*, never as met.

### D5 — Eval fixtures (ADOPTTEL-05)

Added to `evals/memory-recall/cases.json` and the belief eval set:

- **fresh employee, prior work exists** — probe must surface the prior item at `before_plan`
- **no prior work** — must skip with a receipt and fabricate nothing
- **junk save** — coach-back fires with the right flag
- **duplicate save** — dedupe hit and `isRediscovery` set
- **old-critical beats recent-noise** — regression-guards Phase 118 ranking *through the new seam* (the existing Phase 118 fixture only covers the kernel directly)

## Implementation Steps

1. Confirm each Phase 191-193 producer is emitting live before building any panel row; record which are verified. Do not build a row for an unverified producer without a `known-unwired` state.
2. Extend the NOC read model with the D1 aggregations (per-agent, per-harness, window-aware per `NOCUX-05`).
3. Build the panel with all five semantic states; keep it behind *Show advanced* until producers verify.
4. Generalize the detector per D2; add the two new finding types; route to Attention.
5. Write `scripts/check-gsd-memory-receipts.mjs` + `.test.mjs` including the must-fail fixture; wire into CI.
6. Add the D5 eval fixtures.
7. Record SLO baselines with dates; verification.

## Risks

- **Measuring before producers land.** The likeliest failure is shipping a beautiful panel over empty tables — exactly the Phase 117 outcome this milestone exists to fix. Step 1 is a hard gate: verify each producer live first.
- **Gate blocks legitimate work.** A phase genuinely needing no memory (pure mechanical cleanup) must be able to close. The typed skip receipt is the escape hatch; it must be cheap and honest, not a rubber stamp — record the reason.
- **Detector false positives.** Broadening beyond research-without-persist risks flagging trivial sessions. Reuse v3.0's substantiveness thresholds; tune on real data before routing to Attention at warn severity.
- **SLO targets are guesses.** 70% is an initial figure, not evidence. Measure first, then set the target from the observed baseline and say so in the roadmap.
