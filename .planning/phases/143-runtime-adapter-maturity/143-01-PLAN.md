# Phase 143 Plan 01 — Runtime Adapter Maturity Matrix

**Phase:** 143  
**Milestone:** v8.5  
**Requirements:** FLEET-05..08  
**Status:** potential plan  

## Goal

Publish an honest maturity matrix for all MemroOS runtime targets so fleet diagrams stop treating Hermes / OpenClaw / Claude Code / Codex as equal.

## Tasks

1. Inventory install targets from `scripts/install-agent-integrations.sh`
2. For each runtime, classify T1 / T2 / T3:
   - **T1** — shipped + smoke-tested + governance-hooked (pre-exec path ready)
   - **T2** — installed + partial contract (memory/MCP only, thin dispatch)
   - **T3** — stub / install-only / unproven
3. File `docs/runtime-adapter-maturity.md` + link from architecture
4. NOC or ops page: show maturity badge per registered agent type (optional UI if cheap; otherwise docs-only for this phase)
5. CI drift gate optional: installer targets listed in maturity doc must match installer script

## Success criteria

1. All nine install targets appear in the matrix with T1/T2/T3 + evidence link
2. Hermes + OpenClaw maturity claims cite Paperclip/MemroOS adapter evidence where relevant
3. Unproven adapters are explicitly T3 — no silent promotion
