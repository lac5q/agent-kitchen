# Phase 144 Plan 01 — LangGraph Peer Contract + Checkpoint Durability

**Phase:** 144  
**Milestone:** v8.5  
**Requirements:** FLEET-09..12  
**Status:** potential plan  

## Goal

Pin LangGraph as a **peer runtime service** under the orchestration proxy: input/output schema, checkpoint store layout, HIL interrupt protocol, failure modes, and durability path for checkpoints (litestream or shared Postgres). Do not rebuild LangGraph features inside MemroOS.

## Tasks

1. Expand `docs/integrations/langgraph.md` to a full peer contract:
   - Who owns graph definition vs who owns agent identity/memory/audit
   - Checkpoint store path / env vars
   - HIL queue interaction with MemroOS approvals
   - Failure modes (host loss, desync, timeout)
2. Document SQLite ownership split (MemroOS registry vs LangGraph checkpoints)
3. Implement or document **minimum durability**: litestream config **or** Postgres checkpointer option behind flag
4. Smoke: one multi-step graph with interrupt → resume, receipt in run ledger / audit

## Success criteria

1. Contract doc answers: input schema, output schema, checkpoint layout, HIL protocol, failure modes
2. Durability path is either running in dev or explicitly "flagged experimental" with restore drill steps
3. No reimplementation of StateGraph inside Next routes

## Verification

- Contract checklist complete in docs
- Smoke test command documented and green
