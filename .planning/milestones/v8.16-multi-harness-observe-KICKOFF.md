## Intent

Make MemRoOS learn **relevant work from agents already onboarded** to MemRoOS (registry + MCP), across harnesses — with:

1. **Minimal client setup** — remote MCP + one observe onboard (and installer TARGET for Pi).
2. **Autonomous capture** — not “hope the agent calls `knowledge_write`.”
3. **Balanced storage** — default depth `relevant`; upgradable to `full` later.
4. **First-class Pi** — Pi is already `AgentPlatform` `"pi"`; sessions at `~/.pi/agent/sessions/**/*.jsonl`. **Wave 1**, not deferred.

## Honest constraint

**MCP alone cannot wiretap sessions.** Product = MCP (brain for onboarded agents) + observe sidecar (capture).

## Capture depth (default = relevant)

| Depth | Store | Don’t store (by default) |
|-------|--------|---------------------------|
| `summary` | TLDR, repo, exit | Decisions detail, transcripts |
| **`relevant`** | Summary + decisions/actions/blockers + candidates | Full turn-by-turn chat in vector index |
| `full` | Relevant + sealed fuller transcripts | Unredacted secrets; unlabeled PII in shared gold |
